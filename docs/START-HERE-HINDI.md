# shrinimbark.org — आरम्भ करने की सरल हिन्दी मार्गदर्शिका

आपको प्रोग्रामिंग सीखने की जरूरत नहीं है। नीचे दिए गए चरणों को क्रम से करें। यदि किसी स्क्रीन पर अलग विकल्प दिखे तो उसका स्क्रीनशॉट भेजें; पासवर्ड या OTP छिपाकर रखें।

## भाग 1 — अपने कम्प्यूटर पर वेबसाइट देखना

1. वेबसाइट परियोजना की ZIP फाइल डाउनलोड करें।
2. ZIP पर दायाँ क्लिक → **Extract All…** → **Extract** करें।
3. निकले हुए `shrinimbark-nextjs` फ़ोल्डर को खोलें।
4. Node.js की आधिकारिक वेबसाइट `https://nodejs.org/` खोलें। LTS संस्करण डाउनलोड करके सामान्य सॉफ़्टवेयर की तरह स्थापित करें।
5. Windows Start में `PowerShell` खोजकर खोलें।
6. फ़ोल्डर के पते के लिए File Explorer में `shrinimbark-nextjs` फ़ोल्डर खोलें। ऊपर address bar पर क्लिक करें, `powershell` लिखें और Enter दबाएँ। इससे PowerShell सही फ़ोल्डर में खुलेगा।
7. यह लिखें और Enter दबाएँ: `npm install`
8. स्थापना पूरी हो जाए तो यह लिखें: `npm run dev`
9. Chrome में `http://localhost:3000` खोलें। वेबसाइट आपके कम्प्यूटर पर दिखेगी।
10. बन्द करने के लिए PowerShell में `Ctrl + C` दबाएँ।

## भाग 2 — वेबसाइट को इंटरनेट पर प्रकाशित करना

इसे प्रकाशित करने के लिए GitHub (कोड रखने की जगह) और Vercel (वेबसाइट होस्ट करने की सेवा) का उपयोग प्रस्तावित है।

1. GitHub पर अपना खाता बनाएँ।
2. GitHub में **New repository** चुनें। नाम `shrinimbark-website` रखें और **Private** चुनें।
3. इस परियोजना के फ़ोल्डर की सभी फाइलें उस repository में अपलोड करें। ZIP फाइल को repository में रखने के बजाय ZIP खोलकर उसके भीतर की फाइलें अपलोड करें।
4. Vercel पर GitHub खाते से sign in करें।
5. **Add New → Project** चुनें और `shrinimbark-website` repository import करें।
6. Framework के रूप में Next.js दिखेगा। Build command और output directory को सामान्यतः न बदलें। **Deploy** दबाएँ।
7. Deploy सफल होने पर Vercel एक अस्थायी वेबसाइट पता देगा। पहले उस पते पर सभी पृष्ठ जाँचें।
8. Vercel Project → **Settings → Domains** खोलें और `shrinimbark.org` जोड़ें। `www.shrinimbark.org` भी जोड़ सकते हैं।
9. Vercel जो DNS रिकॉर्ड दिखाए, वही रिकॉर्ड अपने domain registrar के DNS पैनल में जोड़ें। DNS रिकॉर्ड का अनुमान न लगाएँ।
10. यदि domain पर पहले से ईमेल सेवा चलती है तो MX records को न हटाएँ। DNS बदलने से पहले उनका स्क्रीनशॉट/बैकअप रखें।
11. Vercel में domain verification पूरा होने के बाद `https://shrinimbark.org` खोलकर जाँचें।

## भाग 3 — वेबसाइट को पूर्ण संस्थागत पोर्टल बनाने के लिए आवश्यक निर्णय

- आधिकारिक सम्पर्क ईमेल कौन-सा प्रकाशित करना है?
- वेबसाइट पर कौन-सा लोगो/चिह्न आधिकारिक होगा?
- क्या किसी सम्पादक/शोधकर्ता को सामग्री प्रकाशित करने की अनुमति होगी? उनके नाम और भूमिका।
- किन ग्रन्थों/पाण्डुलिपियों को डिजिटल रूप में प्रकाशित करने की अनुमति उपलब्ध है?
- किस विद्वान/सम्पादक से संस्कृत, दर्शन, इतिहास और अनुष्ठान सामग्री की समीक्षा करानी है?

## सुरक्षा सावधानियाँ

- पासवर्ड, OTP, recovery code या payment जानकारी चैट में न भेजें।
- Registrar, GitHub और Vercel खातों पर two-factor authentication चालू रखें।
- domain के DNS में MX records न हटाएँ, जब तक ईमेल सेवा बदलने का निर्णय न हो।
- वेबसाइट पर किसी संस्था की आधिकारिक मान्यता, गुरु-परम्परा, तिथि या अनुष्ठान-विधान का दावा स्रोत-सत्यापन के बिना प्रकाशित न करें।
